# Student Grade Management System

### Project Purpose
This Java console application helps to digitally manage student records including their Student IDs, Names, and Marks.

### Key Features Included:
1. Add a Student (ID, Name, Marks)
2. Display All Students
3. Search for a Student by ID
4. Calculate and Display Average Mark

### How to run the program
1. Compile the files: javac Main.java Student.java
2. Run the program: java Main
